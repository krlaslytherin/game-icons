# Game Icons — unofficial CSS library

4,180 monochrome icons based on [Game-Icons.net](https://game-icons.net/). SVG paths converted to an embedded WOFF2 webfont.

## Usage

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/krlaslytherin/game-icons@main/game-icons.css">
<i class="gi gi-crystal-ball" aria-hidden="true"></i>
```

Use `font-size` and `color` to customize. See `index.html` for the searchable catalog. Names repeated in the original source have an author suffix, so each icon has its own class.
